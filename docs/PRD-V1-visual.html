SuperVoice

AI voice agent platform for Indian real estate SMBs — prepaid wallet, custom prompts, inbound & outbound calls, swappable telephony / STT / LLM / TTS.

PRD v1.3 Phase 1: India Phase 2: Global Pipecat + adapters Knowlarity + Plivo INR prepaid wallet

Phase-wise strategy

One platform core. Phase 1 optimizes for India; Phase 2 adds regions and compliance packs without forking the product.

Phase 1 — Now (V1)

India · Real estate SMB

  • INR wallet — recharge before use (UPI, cards)
  • Inbound + outbound AI agents
  • Agent studio with custom prompts
  • Default telephony: Knowlarity (Gupshup)
  • Alternate: Plivo
  • NDNC / DND, IST calling windows, GST receipts
  • English first; Hindi on roadmap
  • Two-way human calling — RM-enabled only
Phase 2 — Later

Global · More verticals

  • Multi-currency wallet
  • US / UK / ME and local DIDs
  • Compliance packs (e.g. TCPA, GDPR)
  • Regional telephony defaults (e.g. Plivo)
  • More industries beyond real estate
  • Additional languages & locales

Release roadmap (milestones)

Engineering and product phases from lab to GA. M5 is post-GA premium capability.

M0 — Foundation
Voice pipeline + telephony adapter #1

Pipecat loop; Knowlarity or Plivo (eng picks order); one STT / LLM / TTS.

Exit: stable 10-min lab call on Indian number.

M0b — Telephony #2
Second CPaaS adapter

Remaining provider (Plivo or Knowlarity).

Exit: same test suite passes on both.

M1 — Wallet + Agent studio
Prepaid + prompt-based agents

Recharge, hard gate at ₹0, custom prompts, sandbox call.

Exit: cannot place calls without balance.

M2 — Inbound beta
Live inbound for design partner

PSTN inbound, listing + buyer qual, transcripts, business hours.

Exit: 1 prepaid design partner live.

M3 — Outbound alpha
Campaigns + compliance

Speed-to-lead, DNC, IST windows, wallet metering.

Exit: 100 calls; ledger reconciles.

M4 — V1 GA
India real estate launch

Inbound + outbound, CRM/webhook, reporting, RM console.

Exit: 3 paying SMB teams; SLOs met 30 days.

M4b — API & webhooks
Developer integrations

API keys, outbound API, webhooks, custom analysis fields.

Exit: partner integration on all_processing_completed.

M5 — Two-way calling
RM-gated human calling tool

Internal enablement only; audit trail; wallet metering.

Exit: 2–3 entitled tenant pilots.
